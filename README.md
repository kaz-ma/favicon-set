# favicon・OG画像 一式ジェネレーター

**画像を1枚入れると、アイコン10種とOG画像、貼り付け用タグまで出ます。**

👉 **[kaz-ma.github.io/favicon-set/](https://kaz-ma.github.io/favicon-set/)**

---

## 出るもの

| ファイル | 寸法 | 用途 |
|---|---|---|
| `favicon.ico` | 16・32・48 を1つに | 旧ブラウザ・ブックマーク |
| `favicon-16x16.png` / `-32x32` / `-48x48` | 各サイズ | 標準 |
| `apple-touch-icon.png` | 180×180 | iOS のホーム画面 |
| `android-chrome-192x192.png` / `-512x512` | 各サイズ | Android / PWA |
| `maskable-512x512.png` | 512×512 | Android のマスク切り抜き用 |
| `og-image.png` | 1200×630 | SNSで共有されたときのカード |
| `site.webmanifest` | ─ | PWA |

**貼り付け用の `<link>` / `<meta>` もまとめて出ます。**

## 細かいが実害のある3点を押さえています

### apple-touch-icon だけ、透過させません

**iOS は透過部分を黒で塗ります。** 透過のまま渡すと、暗いロゴが消えます。
背景を「透過」に設定していても、このファイルだけは白を敷きます。**黙って変えず、画面に理由を出します。**

### maskable は中央80%に収めます

Android はアイコンを円や角丸で切り抜きます。安全なのは中央の直径80%だけです。
余白の設定とは独立に、常に80%へ収めます。

### ZIPにしません

Mac で作った ZIP が Windows で文字化けし、ファイル名に `:` が入って**展開すら失敗する**事故を踏んでいます。
150ms 間隔の連続ダウンロードにしてあります。止まった場合は各行のボタンで個別に取れます。

## OG画像は文字を乗せられます

タイトル・サブタイトル・背景（単色／元画像＋暗幕）・ロゴの位置（9分割）を指定できます。
**日本語の自動折り返しに対応**しています（空白で切り、1トークンが長すぎるときは文字単位で割ります）。

## 仕様

| | |
|---|---|
| ファイル | **単一HTML 1つ**。外部のCSS・JS・フォント・画像を1つも読みません |
| 通信 | **ゼロ。** 画像はブラウザの外に出ません |
| 動かし方 | `index.html` をダブルクリック |
| 入力 | PNG / JPEG / WebP / **SVG** / GIF / AVIF。正方形でなければ短辺に合わせて中央で切り取ります |
| 検査 | 画面の「セルフチェック」から39件の検査を実行できます（ICOのバイト構造、透過、セーフゾーン、折り返しなど） |

## タグのパスは、置き場所に合わせて自動で変わります

「サイトのURL」を入れると、**そのパスに合わせた形**でタグを出します。

| 入力したサイトURL | 出るパス |
|---|---|
| （未入力） | `favicon.ico`（相対。HTMLと同じフォルダにある前提） |
| `https://example.com` | `/favicon.ico` |
| `https://kaz-ma.github.io/imgset/` | `/imgset/favicon.ico` |

**常に `/favicon.ico` で出すと、サブディレクトリに置いたサイトでは全部404になります。**
GitHub Pages のプロジェクトページ（`user.github.io/<repo>/`）がまさにそれで、**実際に踏んで直しました。**

`og:image` だけは絶対URLのままです。相対パスではSNS側が読めないためです。

## 既知の制限

| | |
|---|---|
| PWAでないサイトにも `site.webmanifest` を出す | 不要なら、その行とファイルを使わないでください |
| PNGを最適化していない | Canvas の `toBlob` は無圧縮に近いため、容量が大きめに出ます |
